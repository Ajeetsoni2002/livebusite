UNIT I Introduction to Electrical Engg. & DC Circuits

1. Introduction: Generation, Transmission, Distribution & Utilization

Electrical energy ek chain mein user tak pahunchti hai: Generation (11–33 kV) → Step-up → Transmission (220/400/765 kV) → Distribution (11 kV / 415 V) → Utilization (230 V), India mein 50 Hz.

  • Generation: Heat, water, wind, sun, nuclear energy ko alternator se electrical energy mein badalna.
  • Transmission: High voltage (HV/EHV) par bulk power door tak bhejna. High voltage kyun? P = VI fixed ho to V badhane par I kam → I²R loss kam, conductor patla (sasta).
  • Distribution: Substation se consumers tak: primary (11 kV feeders) aur secondary (415 V 3-ph / 230 V 1-ph).
  • Utilization: Motors, lighting, heating, traction, electrolysis etc. mein use.

2. DC Circuits — Basics

Ohm's law: V = IR (temperature constant).

KCL: Kisi node par ∑I = 0 (aane wali current = jaane wali). Charge conservation.

KVL: Kisi closed loop mein ∑V = 0 (∑ emf = ∑ IR drops). Energy conservation.

Series: Req = R₁+R₂+…; Parallel: 1/Req = 1/R₁+1/R₂+…

Maxwell's Loop (Mesh) Equations

Har independent loop mein ek circulating (loop) current assume karo (clockwise). Common branch mein net current = difference of loop currents. Har loop par KVL lagao → simultaneous equations. Number of equations = b − n + 1 (b = branches, n = nodes).

Matrix form: [R][I] = [V]; R11 = self-resistance of loop 1, R12 = −(common resistance).

Node (Nodal) Equations

Ek node ko reference (ground) lo. Baaki (n−1) nodes ke voltages unknown. Har node par KCL: ∑ (Vnode − Vadjacent)/R = source current. Jab nodes kam aur loops zyada hon tab nodal better hai.

Source Conversion

Practical voltage source (V in series with R) ⇔ practical current source (I in parallel with same R).

I = V/R    ⇔    V = I·R

Ideal voltage source (R=0) aur ideal current source (R=∞) ka conversion possible nahi.

3. Network Theorems

(a) Superposition Theorem

Linear, bilateral network mein multiple sources hon to kisi branch ka response = har source akele lagane par mile responses ka algebraic sum. Ek source rakhte waqt baaki voltage sources short karo, current sources open karo (internal resistance rehne do). Power par apply nahi hota (P ∝ I², non-linear).

(b) Thevenin's Theorem

Koi bhi linear two-terminal network = ek voltage source Vth series mein Rth.

  • Vth = load hata kar terminals A-B ka open-circuit voltage.
  • Rth = sources ko replace (V short, I open) karke A-B se dekha gaya resistance.
  • Load current: IL = Vth/(Rth + RL)

(c) Norton's Theorem

Network = current source IN parallel mein RN. IN = A-B short karke short-circuit current; RN = Rth. Relation: Vth = INRN; IL = IN·RN/(RN+RL).

Solved Example 12 V source, 4 Ω series, phir 12 Ω shunt across A-B; RL = 6 Ω. Thevenin: Vth = 12×12/(4+12) = 9 V; Rth = 4∥12 = 3 Ω. IL = 9/(3+6) = 1 A. Norton: IN = 12/4 = 3 A, RN = 3 Ω → IL = 3×3/9 = 1 A (same ✓). Max power: RL = 3 Ω, Pmax = 9²/(4×3) = 6.75 W.

(d) Maximum Power Transfer Theorem

DC network se load ko maximum power tab milegi jab RL = Rth. Is condition par efficiency sirf 50% hoti hai.

Pmax = Vth²4Rth    (AC: ZL = Zth* i.e. complex conjugate)

Proof sketch: P = Vth²RL/(Rth+RL)²; dP/dRL = 0 ⇒ RL = Rth.

(e) Millman's Theorem

Kai parallel voltage sources (har ek apne series R ke saath) ko ek equivalent source se replace kar sakte hain:

Veq = V₁G₁ + V₂G₂ + … + VnGnG₁ + G₂ + … + Gn ,   Req = 1G₁+G₂+…+Gn ,   G = 1/R

Example: 10 V/2 Ω aur 6 V/2 Ω parallel → Veq = (5+3)/(0.5+0.5) = 8 V, Req = 1 Ω.

(f) Reciprocity Theorem

Linear, bilateral, single-source network mein: agar branch-1 mein lagi source E se branch-2 mein current I aata hai, to wahi E branch-2 mein lagane par branch-1 mein same I aayega. Ratio E/I = constant (transfer resistance). Dependent sources ke saath valid nahi.

(g) Star–Delta (Y–Δ) Transformation

Δ → Y: RA = RABRCA / (RAB+RBC+RCA) (do adjacent ka product / sum)

Y → Δ: RAB = RA + RB + RARB/RC

Balanced: RY = RΔ/3, RΔ = 3RY. Example: Δ ke teen 9 Ω → Y ke teen 3 Ω.

UNIT II Single Phase & Poly Phase AC Circuits

1. Alternating Waves & Values

Alternating quantity wo hai jiska magnitude time ke saath badalta hai aur direction periodically reverse hoti hai. Sinusoidal wave sabse common: instantaneous value v = Vm sin ωt, ω = 2πf, T = 1/f. Waves: sinusoidal, square, triangular, sawtooth.

  • Instantaneous value: kisi bhi instant par value (v, i).
  • Peak/Max value (Vm): ek cycle ki highest value.
  • Average value: half-cycle ka mean (full cycle ka sine average = 0). Vav = 2Vm/π = 0.637Vm
  • RMS (effective) value: wo DC value jo same resistor mein same heat produce kare. Vrms = Vm/√2 = 0.707Vm

2. Phasor, Power & Power Factor

Phasor = rotating vector (anticlockwise, ω rad/s) jiski length RMS value aur angle phase batata hai. Phase difference φ: leading/lagging. j-operator: A = a + jb = |A|∠θ.

Low pf ke nuksaan: same power ke liye zyada current → zyada copper loss, bada conductor, poor voltage regulation. Improvement: shunt capacitor, synchronous condenser.

3. Single Phase Series & Parallel Circuits

Series RLC: Z = R + j(XL − XC), |Z| = √(R² + (XL−XC)²), φ = tan⁻¹((XL−XC)/R). Current common hai, isliye I ko reference lo. VR in phase, VL 90° aage, VC 90° peeche.

XL > XC → inductive (lagging); XL < XC → capacitive (leading).

Parallel circuit: Voltage common (reference). Admittance Y = 1/Z = G − jB (S). Branch currents ka phasor sum = total current. Ytotal = Y₁ + Y₂ + …

Solved Example R = 10 Ω, L = 0.1 H, C = 100 µF series, 230 V, 50 Hz. XL = 31.4 Ω, XC = 31.83 Ω → X = −0.43 Ω; Z ≈ 10.01 Ω, I ≈ 22.98 A, pf ≈ 0.999 leading (almost resonance), P = I²R ≈ 5.28 kW.

4. Resonance

Series resonance: XL = XC ⇒ Z = R (minimum), I = V/R (maximum), pf = 1. Isliye acceptor circuit. Voltage magnification: VL = VC = Q·V.

fr = 12π√(LC) ;   Q = ωrLR = 1R√(L/C) ; BW = f₂ − f₁ = R/(2πL) = fr/Q

Parallel resonance (coil R-L ∥ C): Zdyn = L/(CR) (maximum), line current minimum, pf = 1 → rejector circuit. Current magnification = Q.

fr = 12π√(1LC − R²L²)

5. Poly Phase (Three Phase) AC Circuits

3-phase system mein teen equal emf, 120° apart. Fayde: same power ke liye kam conductor material, constant (non-pulsating) power, 3-ph induction motor self-starting, better efficiency.

Phase sequence: Order jisme phases apna maximum value lete hain: R-Y-B (positive). Reverse (R-B-Y) karne par 3-ph motor ki direction ulti ho jaati hai.

Three Phase Power Measurement & Two Wattmeter Method

Methods: three-wattmeter (4-wire, unbalanced bhi), two-wattmeter (3-wire, balanced/unbalanced, star/delta), one-wattmeter (balanced only). Blondel's theorem: n-wire system ke liye (n−1) wattmeter kaafi hain.

W₁ = VLIL cos(30° − φ),   W₂ = VLIL cos(30° + φ) P = W₁ + W₂ ;   tan φ = √3 W₁ − W₂W₁ + W₂

Q = √3(W₁ − W₂).

pf effect: pf = 1 → W₁ = W₂; pf = 0.5 → W₂ = 0; pf < 0.5 → W₂ negative (PC/CC reverse karke padho, subtract karo); pf = 0 → W₁ = −W₂, P = 0.

Example W₁ = 5 kW, W₂ = 1 kW. P = 6 kW; tan φ = √3×4/6 = 1.155 ⇒ φ = 49.1°, pf = 0.655.

UNIT III Magnetic Circuits, Electrostatics & Transformer

1. Fundamental Definitions

Flux φ — Weber (Wb)

Flux density B = φ/A — Wb/m² = Tesla

Field intensity H = NI/l — AT/m

Permeability μ = μ₀μr = B/H, μ₀ = 4π×10⁻⁷ H/m

MMF F = NI — Ampere-turns (AT)

Reluctance S = l/(μ₀μrA) — AT/Wb; Permeance = 1/S

Magnetic Ohm's law: φ = MMFReluctance = NIl/(μ₀μrA)

Ampere's circuital law: Closed path ke along H ka line integral = enclosed current: ∮H·dl = ∑I = NI. Isi se MMF calculate hota hai.

Faraday's law: Changing flux se emf induce: e = −N dφ/dt.

Lenz's law: Induced emf/current ki direction aisi hoti hai ki wo apne cause (flux change) ko oppose kare (isliye minus sign).

Fleming's right hand rule (generator) — thumb motion, first finger field, middle finger induced current.

Calculation of MMF (series & composite magnetic circuit)

Har part (iron, air gap) ke liye: AT = H × l = (B/μ₀μr) × l. Total AT = ∑ AT of all parts (series circuit). Air gap mein μr = 1, isliye chhote gap ko bhi bahut AT chahiye.

Example Iron ring: mean length 1 m, A = 10 cm², μr = 1000, air gap 1 mm, φ = 1 mWb. B = 1 T. Iron AT = 1×1/(4π×10⁻⁷×1000) = 796; Gap AT = 1×0.001/(4π×10⁻⁷) = 796. Total ≈ 1592 AT (1 mm gap = 1 m iron!).

2. Induced EMFs & Inductance

Dynamically induced emf: Conductor field mein move kare (generator). e = Blv sin θ.

Statically induced emf: Conductor stationary, flux change ho:
(i) Self-induced — coil ka apna current change: e = −L di/dt.
(ii) Mutually induced — paas wali coil ke current change se (transformer): e₂ = −M di₁/dt.

InductanceL = NφI = N²S = μ₀μrN²Al (H)M = N₂φ₁₂I₁ = N₁N₂S ;   M = k√(L₁L₂)Energy stored = ½LI² ; Series aiding: L = L₁+L₂+2M

Coefficient of coupling (k): k = M/√(L₁L₂), 0 ≤ k ≤ 1. k = 1 → tight coupling (saara flux dono coils link kare); k ≈ 0 → loosely coupled.

Leakage flux: Jo flux desired path (core/air gap) se bahar complete ho jaata hai. Leakage coefficient λ = total flux / useful flux (1.1–1.25). Fringing: Air gap mein flux lines bahar ki taraf phail jaati hain → effective gap area badh jaata hai, B kam ho jaata hai.

3. B-H Curve, Hysteresis & Eddy Current Loss

B-H (magnetisation) curve: Ferromagnetic material mein H badhane par B pehle tezi se badhta hai, phir saturation aa jaata hai (μ constant nahi).

Hysteresis: B ka H se peeche (lag) rehna. Retentivity/Residual flux Br = H=0 par bacha B. Coercive force Hc = B ko zero karne ke liye ulta H. Loop ka area = per cycle per m³ energy loss.

Core loss: Hysteresis Ph = η Bm1.6 f V (W) [Steinmetz] ;   Eddy Pe = Ke Bm² f² t² V (W)

Eddy currents: Changing flux core mein khud circulating currents induce karta hai → I²R heat. Kam karne ke liye: laminated core (thin sheets 0.35–0.5 mm, varnish insulated), high resistivity silicon steel. Hysteresis kam karne ke liye: silicon steel / CRGO (narrow loop). Soft magnetic (narrow loop) → transformer/machines; hard magnetic (wide loop) → permanent magnets.

4. Transformer

Transformer ek static device hai jo AC power ko ek circuit se doosre mein mutual induction se transfer karta hai, frequency same rehti hai, voltage/current level badalta hai.

Construction: Laminated CRGO silicon steel core; primary & secondary windings (copper/Al); insulation; tank, transformer oil (cooling + insulation), conservator, breather, bushings.

Principle: Primary par AC → core mein alternating flux → secondary se link → mutually induced emf (Faraday's law). DC par kaam nahi karta (dφ/dt = 0, high current se jal sakta hai).

Types: (i) Core construction — core type (winding core ko gherti hai), shell type (core winding ko gherta hai), berry type; (ii) step-up (N₂>N₁) / step-down; (iii) single / three phase; (iv) use — power, distribution, instrument (CT/PT), auto, welding.

EMF eq.: E₁ = 4.44 f N₁ φm ;   E₂ = 4.44 f N₂ φm ;   K = E₂E₁ = N₂N₁ = I₁I₂

Derivation: φ = φm sin ωt; average dφ/dt (quarter cycle) = φm/(1/4f) = 4fφm → Eav/turn = 4fφm; × form factor 1.11 → Erms/turn = 4.44 fφm.

Example: 2200/220 V, 50 Hz, φm = 0.01 Wb → N₁ = 2200/(4.44×50×0.01) ≈ 991, N₂ ≈ 99.

Phasor Diagram — No Load & On Load

No load: I₀ = 2–5% of rated; I₀ ke do components: Iμ = I₀ sin φ₀ (magnetising, φ ke in-phase) aur Iw = I₀ cos φ₀ (core-loss/working, V₁ ke in-phase). E₁, E₂ flux se 90° peeche. No-load pf bahut low (0.1–0.2).

On load: I₂ flow karta hai → secondary MMF N₂I₂ flux ko oppose karta hai → primary extra current I₂' = K I₂ leta hai taaki flux constant rahe. I₁ = I₀ + I₂' (phasor). Practical: V₂ = E₂ − I₂(R₂ + jX₂), V₁ = −E₁ + I₁(R₁ + jX₁).

Equivalent Circuit

Approximate circuit: shunt branch (R₀‖X₀) ko input terminals par shift → R₀₁ = R₁ + R₂/K², X₀₁ = X₁ + X₂/K², Z₀₁ = √(R₀₁² + X₀₁²).

Losses, Efficiency & All-day Efficiency

  • Iron/core loss Pi (hysteresis + eddy) — constant loss (har load par same).
  • Copper loss Pcu = I₁²R₀₁ — variable loss, ∝ (load)². x fraction load par = x²Pcu,FL.
Efficiencyη = x·S·cos φx·S·cos φ + Pi + x²Pcu,FL × 100% ;   ηmax when Pcu = Pi ⇒ x = √(Pi/Pcu,FL)

All-day (energy) efficiency = output kWh in 24 h / input kWh in 24 h. Distribution transformers ke liye important hai kyunki wo 24 h energised rehte hain (iron loss 24 h) par load variable hota hai. Isliye inhe low iron loss ke saath design karte hain.

Example 20 kVA, Pi = 200 W, Pcu,FL = 400 W, pf 0.8. Full load: η = 16000/(16000+600) = 96.4%. Half load: output 8000 W, losses 200 + 100 = 300 → η = 96.4%. ηmax at x = √(0.5) = 0.707 load.

Voltage Regulation

% Reg = V2,NL − V2,FLV2,NL ×100 ≈ I₂(R₀₂ cos φ ± X₀₂ sin φ)V₂ ×100   (+ lagging, − leading)

Leading pf par regulation negative bhi ho sakta hai (load par voltage badh jaata hai). Kam regulation achha.

Welding, Auto & Three-phase Transformer

  • Welding transformer: Step-down, low voltage (≈ 15–80 V open circuit) aur very high current (100s of A); high leakage reactance (drooping characteristic) taaki arc stable rahe aur short-circuit current limit ho. Current control: tapped reactor / movable core / magnetic shunt.
  • Auto transformer: Sirf ek winding, part common to primary & secondary. Power partly conduction se, partly induction se transfer. Copper saving = K × (two-winding copper) jahan K = VLV/VHV. Fayde: sasta, chhota, better η & regulation. Nuksaan: no electrical isolation. Use: variac, motor starting, interconnecting grids.
  • Three-phase transformer: 3 single-phase units ka bank ya ek common core (core/shell type) par 3 primary + 3 secondary. Connections: Y-Y, Δ-Δ, Y-Δ (step-down at substation), Δ-Y (step-up at generating station, distribution). Single 3-ph unit sasta aur chhota hota hai.

UNIT IV DC Machines & AC Machines

1. DC Generator

Principle: Faraday's law of electromagnetic induction — conductor magnetic field mein rotate kare to dynamically induced emf (e = Blv). Direction: Fleming's right hand rule. Armature mein emf AC hoti hai; commutator use DC mein badalta hai.

Construction: Yoke (frame, cast iron/steel, flux path), pole core & pole shoe (flux spread), field winding, armature core (laminated silicon steel, slots), armature winding (lap: A = P; wave: A = 2), commutator (copper segments, mica insulated), brushes (carbon), bearings, shaft.

EMF eq.: Eg = φ Z N P60 A voltsφ = flux/pole (Wb), Z = total conductors, N = rpm, P = poles, A = parallel paths (lap A = P, wave A = 2)

Derivation: Ek conductor ek revolution mein Pφ flux cut karta hai, time 60/N s → emf/conductor = PφN/60; series conductors = Z/A.

2. DC Motor

Principle: Current-carrying conductor magnetic field mein rakhne par force F = BIl lagta hai (Fleming's left hand rule) → torque → rotation.

Back EMF: Rotating armature mein bhi emf induce hoti hai jo supply voltage ko oppose karti hai (Lenz's law):

Eb = φZNP60A ;   V = Eb + IaRa

Eb current ko self-regulate karti hai; start par Eb = 0 → bahut high current, isliye starter chahiye. Speed N ∝ Eb/φ.

TorqueTa = 0.159 φ Z Ia PA N·mTa ∝ φIa ;   EbIa = Ta·2πN60T = 9.55 EbIa/N
Example 220 V shunt motor, Ra = 0.5 Ω, Ia = 20 A, 1000 rpm. Eb = 220 − 10 = 210 V. T = 9.55×210×20/1000 ≈ 40.1 N·m. Agar Ia = 40 A (same φ): Eb = 200 V → N = 1000×200/210 ≈ 952 rpm.

Mechanical (Speed–Torque) Characteristics

  • Shunt motor: φ ≈ constant → T ∝ Ia; speed almost constant (5–10% droop). Constant speed motor.
  • Series motor: φ ∝ Ia (before saturation) → T ∝ Ia²; N ∝ 1/Ia. High starting torque; no-load par kabhi start mat karo (speed dangerously high).
  • Compound: beech ki characteristics.

Armature Reaction, Commutation & Interpoles

  • Armature reaction: Armature current ka flux main field flux ko affect karta hai: (i) cross-magnetising — field distort hota hai, MNA (magnetic neutral axis) shift (generator mein rotation ki direction mein, motor mein opposite); (ii) demagnetising — main flux kam (saturation ki wajah se). Remedy: compensating winding (pole face mein), interpoles, high reluctance pole tips.
  • Commutation: Coil jab brush ke neeche short-circuit hoti hai, uska current +I se −I reverse hona. Coil ki self-inductance (reactance voltage) reversal ko delay karti hai → sparking. Ideal = linear commutation. Improvement: resistance commutation (carbon brushes), EMF commutation — brush shift ya interpoles.
  • Interpoles (commutating poles): Chhote poles main poles ke beech (GNA par), winding armature ke series mein. Ye reactance voltage ko neutralise karte hain aur cross-magnetisation cancel karte hain. Polarity: generator mein next main pole (rotation ki direction mein) jaisi, motor mein previous main pole jaisi.

Starting & Speed Control

Starting: Start par Eb = 0 → Ia = V/Ra (bahut zyada, e.g. 220/0.5 = 440 A). Isliye series resistance wala starter: 3-point starter (shunt motor; NVC — no-volt coil, OLR — overload release), 4-point starter (NVC supply ke across, field control ke liye better), 2-point (series motor). Speed: N ∝ Ebφ = V − IaRaφ

3. AC Machines — Three Phase Induction Motor

Construction: Stator — laminated core, 3-ph distributed winding. Rotor — (i) squirrel cage (Al/Cu bars short-circuited by end rings; simple, rugged, cheap) (ii) slip-ring / wound rotor (3-ph winding, slip rings + external resistance → high starting torque, speed control).

Principle: 3-ph supply stator mein rotating magnetic field (RMF) banata hai jo synchronous speed Ns se ghoomta hai. RMF rotor conductors ko cut karta hai → emf → current (rotor shorted) → force → rotor RMF ki direction mein ghoomta hai (Lenz's law: relative motion kam karne ki koshish). Rotor kabhi Ns tak nahi pahunchta, isliye asynchronous motor.

Ns = 120 fP ;   s = Ns − NNs ; fr = sfE₂r = sE₂ ; X₂r = sX₂ ; Pg : Pcu2 : Pmech = 1 : s : (1−s)Eph = 4.44 f N φ Kw

Torque-slip: Low slip (normal running) par T ∝ s (linear, stable); high slip par T ∝ 1/s. Tmax jab R₂ = sX₂ (sm = R₂/X₂); Tmax R₂ par depend nahi karta. Full-load slip 2–5%. Rotor resistance badhane se starting torque badhta hai (slip-ring motor).

Example: 4-pole, 50 Hz, 1440 rpm → Ns = 1500 rpm, s = 60/1500 = 0.04, rotor frequency = 0.04×50 = 2 Hz.

Types & Applications: Squirrel cage — fans, pumps, lathes, compressors, conveyors (industry ka workhorse). Slip-ring — cranes, hoists, lifts, elevators. Single-phase IM self-starting nahi hai (pulsating field); split-phase / capacitor start → fans, washing machines, refrigerators.

4. Synchronous Machine

Construction: Stator = armature (3-ph winding). Rotor = field (DC excitation via slip rings/brushless exciter). Rotor types: salient pole (projecting poles, large diameter, short length, low speed — hydro, 4–60+ poles) aur non-salient / cylindrical (smooth, small diameter, long, high speed 1500/3000 rpm — steam/gas turbo-alternators, 2 or 4 poles).

Alternator principle: DC excited rotor ko prime mover se ghumate hain → rotating flux stator conductors ko cut karta hai → 3-ph emf (Faraday's law). Stationary armature: HV insulation easy, sirf 2 slip rings (low DC).

EMF eq.: Eph = 4.44 Kc Kd f φ Tph ;   f = PNs120 ;   V = E − I(Ra + jXs)Kc = pitch (coil-span) factor = cos(α/2), Kd = distribution factor, Tph = turns/phase

Synchronous motor: Stator par 3-ph supply (RMF at Ns) + rotor par DC → rotor poles RMF se "lock" ho jaate hain aur exactly Ns par ghoomte hain. Self-starting nahi (damper winding se induction motor ki tarah start). Speed load se independent.

Characteristics: Alternator — terminal voltage vs load (lagging pf par voltage girta hai, leading par badhta hai). Sync motor — V-curves (Ia vs If): under-excited → lagging pf, over-excited → leading pf. Isliye over-excited sync motor ko synchronous condenser (pf improvement) ki tarah use karte hain.

Applications: Alternators — saare power stations. Sync motor — constant speed drives (compressors, rolling mills, cement mills), pf correction, clocks.

UNIT V Power Systems & Protective Devices

1. Conventional Power Systems & Present-day Scenario

Conventional power system: Bade centralised generating stations (thermal, hydro, nuclear) → long HV transmission → distribution → consumers. Power flow one-way, passive consumers, limited monitoring.

Present-day scenario (India): Installed capacity ~450 GW+; coal-based thermal abhi bhi majority generation deta hai, par renewable (solar + wind + hydro) ka share tezi se badh raha hai (target 500 GW non-fossil by 2030). "One Nation One Grid" — saare regional grids synchronised (National Grid). HVDC links, 765 kV AC, rooftop solar, EVs, smart meters, deregulation (GENCO/TRANSCO/DISCOM). Challenges: AT&C losses, RE intermittency.

3. Types of Load & Load Characteristics

Domestic (lights, fans, AC; evening peak), Commercial (shops, offices; day-time), Industrial (nearly constant, high LF), Agricultural (pumps; seasonal), Municipal (street lighting, water supply), Traction (railways, metro; rush-hour peaks).

Load curve: Load (kW) vs time (24 h) graph; area = energy consumed (kWh). Load duration curve = loads descending order mein. By nature: resistive, inductive (motors), capacitive; constant power/current/impedance loads.

4. Fault Analysis

Fault = abnormal condition jab insulation fail ho ya conductors aapas mein / ground se touch ho jaayen → very high current, low voltage, equipment damage, instability.

Fault typeOccurrenceSeverity
Symmetrical — LLL / LLLG (teeno phases short, system balanced rehta hai)~5% (rarest)Most severe
Unsymmetrical — LG (single line to ground)~70–80% (most common)Least severe
LL (line to line) / LLG (double line to ground)~15% / ~10%Medium / medium-high

Analysis: Symmetrical faults → per-unit system + Thevenin equivalent: If = Vth/Zth; fault MVA = base MVA / Zpu. Unsymmetrical faults → symmetrical components (positive, negative, zero sequence; Fortescue). Uses: CB rating, relay setting. Open-circuit (series) faults bhi hote hain.

Example: 10 MVA generator, X = 0.1 pu → 3-ph fault MVA = 10/0.1 = 100 MVA.

5. Protective Devices — Relays

Requirement of relays: Relay fault ko sense karta hai (CT/PT ke through) aur circuit breaker ki trip coil energise karta hai taaki faulty section isolate ho jaaye, baaki system chalta rahe. Chain: Fault → CT/PT → Relay → Trip coil → CB opens.

Qualities: Selectivity (sirf faulty part disconnect), Speed (fast), Sensitivity (chhote fault par bhi operate), Reliability, Stability (external fault par mal-operate na kare), simplicity & economy.

Relay types: Electromagnetic attraction & induction, thermal, static, numerical (microprocessor). By function: overcurrent, distance (impedance), differential (transformer/generator), directional, Buchholz (oil-filled transformer).

6. Circuit Breakers & Operating Principle

Circuit breaker = switching device jo normal aur fault dono conditions mein circuit ko make/break kar sake (manually ya relay se automatically). Operating principle: CB mein fixed aur moving contacts hote hain. Fault par relay trip coil energise karta hai → mechanism (spring/pneumatic) contacts alag karta hai → contacts ke beech arc banta hai → arc ko medium (oil/air/SF₆/vacuum) mein cool/lengthen/deionise karke current zero par extinguish karte hain. Arc extinction: high resistance method (DC/low power) aur low resistance / current-zero method (AC CBs). Terms: restriking voltage, recovery voltage, breaking capacity.

7. Types of Insulators

Overhead line conductors ko towers/poles se insulate aur support karne ke liye. Material: porcelain (most common), toughened glass, polymer/composite (silicone rubber, light weight).

  • Pin type: cross-arm par pin se fixed; up to 33 kV (above it uneconomical).
  • Suspension (disc): discs ki string (~11 kV/disc), conductor neeche latakta hai; above 33 kV; ek disc fail → sirf wahi replace. Conductor ke paas wali disc par max voltage; string efficiency = Vstring/(n × Vnearest disc), guard ring se improve.
  • Strain type: horizontal disc string; high tension — dead end, sharp turns, river crossings.
  • Shackle: spool shape, pole par bolt; LV lines.
  • Post type: base par mounted; substation bus-bars.
  • Stay (egg) insulator: stay wire mein; LV poles.
