UNIT I Computer Fundamentals, Operating System & MS Office

1. Computer – Definition

Definition Computer ek electronic device hai jo user se data (input) leta hai, stored instructions (program) ke according use process karta hai, aur information (output) deta hai; result ko future use ke liye store bhi kar sakta hai.

Characteristics: Speed (nano/pico seconds), Accuracy (GIGO – Garbage In Garbage Out), Diligence (thakta nahi), Versatility, Storage capacity, Automation. Limitation: No IQ, no feelings – khud decision nahi leta.

2. Block Schematic of Digital Computer & Working

  • Input Unit: data ko binary mein convert karke memory tak bhejta hai.
  • Memory Unit: data, program, intermediate results store (primary RAM/ROM/cache; secondary HDD/SSD).
  • ALU: arithmetic (+ − × ÷) aur logical (AND, OR, NOT, compare) operations.
  • Control Unit: instructions ka fetch → decode → execute; sab units ko control signals.
  • Output Unit: result ko human-readable form mein deta hai.

Yaad Rakho: CPU = CU + ALU + Registers. Working cycle = IPOS: Input → Process → Output → Storage; Von Neumann architecture (stored program concept).

3. Classification of Computers

  • By working/data: Analog (continuous data – thermometer, speedometer), Digital (discrete 0/1 – PC), Hybrid (dono – ICU machine, petrol pump).
  • By size & power: Micro (PC/laptop), Mini (small org, multi-user), Mainframe (banks, railways – IBM z), Super (weather/research – PARAM, Frontier; speed in FLOPS).
  • By purpose: General purpose (PC) aur Special purpose (ATM, washing machine controller, traffic light).

8. Operating System

Definition Operating System (OS) ek system software hai jo user aur hardware ke beech interface ka kaam karta hai aur computer ke saare resources (CPU, memory, I/O, files) ko manage karta hai. Ex: Windows, UNIX, Linux, macOS, Android.

Functions of OS: Process management, Memory management, File management, Device (I/O) management, Security & protection, User interface (CLI/GUI), Job accounting, Error detection, Booting.

Types of OS:

Batch OS: similar jobs ka batch, bina user interaction (payroll).

Multiprogramming: memory mein many programs; CPU idle nahi.

Time-sharing / Multitasking: har process ko time-slice (quantum); multi-user (UNIX).

Real-Time OS: fixed deadline mein response; Hard/Soft (missile, ABS brakes, VxWorks).

Distributed OS: many networked computers ek system jaise (Amoeba).

Network OS: server se file/printer sharing (Windows Server, NetWare).

Mobile / Single-user OS: Android, iOS / MS-DOS.

File, Process & Memory Management

  • File Management: files/directories create, delete, read, write, rename; hierarchical directory structure; access permissions; disk space allocation (contiguous, linked, indexed).
  • Process Management: Process = program in execution. States: New → Ready → Running → Waiting → Terminated. OS CPU scheduling karta hai (FCFS, SJF, Round Robin, Priority), PCB (Process Control Block) maintain karta hai, deadlock handle karta hai.
  • Memory Management: process ko memory allocate/deallocate karna; track karna kaun sa part free hai; techniques – partitioning, paging, segmentation, virtual memory (RAM kam ho to disk ka part RAM ki tarah use).

UNIT II Algorithm, Programming Concepts & Introduction to C

1. Algorithm

Definition Algorithm = kisi problem ko solve karne ke liye finite, well-defined, step-by-step instructions ka sequence. Properties: Input (0 ya more), Output (≥1), Definiteness (har step clear), Finiteness (finite steps mein khatam), Effectiveness (simple, doable).

Example – Largest of two numbers: Step 1: Start. Step 2: Read A, B. Step 3: If A > B print A else print B. Step 4: Stop.

Complexity of Algorithm

  • Time complexity: input size n ke function mein algorithm kitna time (steps) leta hai. Space complexity: kitni memory leta hai.
  • Asymptotic notations: Big-O (upper bound / worst case), Ω Omega (lower bound / best case), Θ Theta (tight bound / average).
  • Order: O(1) < O(log n) < O(n) < O(n log n) < O(n2) < O(2n). Ex: Linear search O(n), Binary search O(log n), Bubble sort O(n2).

Flowchart

Flowchart = algorithm ka graphical/pictorial representation standard symbols ke saath.

3. Program Design & Programming Paradigms

Program Design (Program Development Life Cycle): Problem definition → Analysis → Design (algorithm/flowchart/pseudocode) → Coding → Testing & Debugging → Documentation → Maintenance. Approaches: Top-down (bade problem ko chhote modules mein todna – C), Bottom-up (chhote objects se system banana – C++/Java), Modular programming.

Programming Paradigms (programming ki style/approach): Procedural/Structured – program = functions ka sequence, top-down (C, Pascal); Object-Oriented – program = objects (data + functions), bottom-up (C++, Java); Functional – mathematical functions, no side effects (Haskell, LISP); Logic/Declarative – facts + rules (Prolog, SQL); Event-driven – click/key events par code chale (Visual Basic, JavaScript).

4. OOP – Characteristics/Concepts & POP vs OOP

Class: blueprint/template – data members + member functions (ex: class Car).

Object: class ka instance (real entity) – ex: Car c1;

Tokens: Keywords (32 in C89: int, if, while, return...), Identifiers, Constants, Strings, Operators, Special symbols.

2. Functions

Function = self-contained block of code jo specific task karta hai. Benefits: modularity, reusability, easy debugging. Types: Library (printf, sqrt, strlen) aur User-defined. Parts: declaration (prototype), definition, call.

4. Recursion

Jab function khud ko call kare = recursion. Har recursive function mein base condition (termination) zaroori, warna infinite calls → stack overflow. Internally stack use hota hai.

/* Factorial: n! = n * (n-1)! */
long fact(int n) {
    if (n == 0 || n == 1) return 1;  /* base */
    return n * fact(n - 1);
}
/* fact(4) = 4*3*2*1 = 24 */
/* Fibonacci: 0 1 1 2 3 5 8 ... */
int fib(int n) {
    if (n <= 1) return n;         /* base */
    return fib(n - 1) + fib(n - 2);
}

Recursion vs Iteration: recursion – code chhota, elegant, par zyada memory (stack) aur slow; iteration – loop based, fast, kam memory.

5. Pointers

Definition Pointer ek variable hai jo doosre variable ka memory address store karta hai. & = address-of operator, * = dereference (value at address).
int x = 10;
int *p = &x;   /* p stores address of x */
printf("%d %d", x, *p);  /* 10 10 */
printf("%p", (void*)p);  /* address of x */
*p = 20;            /* x becomes 20 */
int **q = &p;       /* pointer to pointer */
  • Pointer arithmetic: p++ next element par jata hai (sizeof(type) bytes aage).
  • Array & pointer: a == &a[0]; a[i] ≡ *(a + i).
  • NULL pointer: kuch point nahi karta (int *p = NULL;).
  • void pointer: generic, kisi bhi type ka address.
  • Dangling pointer: free ki hui memory ko point kare.
  • Dynamic memory: malloc(), calloc(), realloc(), free() (<stdlib.h>).

7. Cyber Attacks

Money Laundering (cyber): illegal (black) money ko online transactions, fake accounts, crypto, shell companies se legal dikhana.

Email Spoofing: email ka "From" address fake karna taaki lage trusted source se aaya hai; phishing ke liye use.

DoS (Denial of Service): server ko fake requests se flood karna taaki genuine users ko service na mile. DDoS = many computers (botnet) se.

Cyber Stalking: internet/email/social media se kisi ko baar-baar harass, follow ya threaten karna.

Logic Bomb: program mein chhupa code jo specific condition/date aane par trigger hokar damage kare (ex: employee ke nikaalne par data delete).

Hacking: bina permission computer/network mein unauthorized access. White hat (ethical), Black hat (criminal), Grey hat.

Spamming: bulk unsolicited (bina maange) emails/messages bhejna – ads, scams, malware links.

Phishing: fake website/email se password, OTP, card details churana.

8. Security Measures, Firewall, Ethics, Cyber Laws

  • Security measures: strong passwords, 2-factor authentication, antivirus/anti-spyware, encryption (plain text → cipher text), regular backup, software updates/patches, access control, digital signature, biometric.
  • Firewall: hardware/software security system jo incoming & outgoing network traffic ko predefined rules ke according monitor aur filter karta hai – trusted internal network aur untrusted internet ke beech "wall". Types: packet filtering, stateful inspection, proxy (application gateway).
  • Computer Ethics & Good Practices: doosre ki files/privacy respect karo, piracy na karo (licensed software), plagiarism na karo, copyright/IPR respect, kisi ko harm na karo, fake news share na karo (Ten Commandments of Computer Ethics).
  • Cyber Laws – IT Act 2000 (India): 17 Oct 2000 se lagu; electronic records & digital signatures ko legal recognition, e-commerce ko support, cyber crimes ki punishment. Amendment 2008. Important sections:

Definition Data = raw facts; Database = logically related data ka organized collection; DBMS = software jo database ko create, store, retrieve, update, manage karne deta hai (MySQL, Oracle, MS Access).

4. Architecture of Database System (Three-Schema) & Data Independence

  • External level (View): individual user ka view – sirf required data dikhta hai.
  • Conceptual level (Logical): poore database ka logical structure – entities, relationships, constraints (DBA define karta hai).
  • Internal level (Physical): data disk par actually kaise store hai – file organisation, indexes.
  • Data Independence = lower level schema change ho to upper level change na karna pade:
  • Logical data independence: conceptual schema change (naya column add) → external views change nahi.
  • Physical data independence: internal schema change (storage, index) → conceptual schema same.

5. Data Dictionary, DBA, Primary Key

  • Data Dictionary: "data about data" (metadata) store karta hai – table/attribute names, data types, constraints, users, access rights (system catalog).
  • DBA (Database Administrator): person jo poore database par central control rakhta hai. Roles: schema definition, storage & access methods, users ko authorization, integrity constraints, backup & recovery, performance tuning.
  • Keys: Primary Key = attribute(s) jo table ki har row ko uniquely identify kare; NULL nahi ho sakta, duplicate nahi, ek table mein ek hi primary key (ex: Roll_No). Others: Super, Candidate, Alternate, Composite, Foreign key (doosri table ki primary key ko refer kare).

6. DDL and DML

DDL – Data Definition LanguageDML – Data Manipulation Language
Database ka structure (schema) define/change karta haiDatabase ke andar ke data ko access/modify karta hai
CREATE, ALTER, DROP, TRUNCATE, RENAMESELECT, INSERT, UPDATE, DELETE
Auto-commit (rollback nahi hota)Rollback possible
Others: DCL (GRANT, REVOKE), TCL (COMMIT, ROLLBACK, SAVEPOINT)
CREATE TABLE Student (Roll INT PRIMARY KEY, Name VARCHAR(20), Marks INT);   -- DDL
INSERT INTO Student VALUES (101, 'Amit', 78);                              -- DML
UPDATE Student SET Marks = 82 WHERE Roll = 101;                            -- DML
SELECT Name, Marks FROM Student WHERE Marks > 60;                          -- DML

7. Cloud Computing

Definition Cloud Computing = internet ke through computing resources (servers, storage, databases, software, networking) ko on-demand, pay-as-you-go basis par provide karna. NIST characteristics: On-demand self-service, Broad network access, Resource pooling, Rapid elasticity, Measured service. Ex: AWS, Azure.

Cloud Infrastructure: data centre hardware (servers, storage, network) + virtualization (hypervisor – ek physical server par many virtual machines) + management software. Front-end (browser) internet se back-end se judta hai.

Pros and Cons of Cloud Computing

Pros: low cost (pay-per-use), scalability/elasticity, anywhere access, auto updates, easy backup & recovery.
Cons: internet dependency, security/privacy risk, limited control, vendor lock-in, downtime risk.
