UNIT I Calculus — Evolutes, Integrals, Beta-Gamma, Volume & Surface

1. Evolutes and Involutes

Kisi curve ke har point par ek circle of curvature hota hai jiska centre centre of curvature kehlata hai. Curve par point move karta hai to ye centre bhi ek nayi curve banata hai.

Definition Evolute = locus of centre of curvature of a given curve. Agar curve C' curve C ka evolute hai, to C ko C' ka Involute kehte hain.
Formula y1=dy/dx, y2=d²y/dx² ρ = (1+y1²)3/2 / |y2| X̄ = x − y1(1+y1²)/y2 ,   Ȳ = y + (1+y1²)/y2

Steps to find Evolute

  1. y1, y2 nikalo (parametric ho to t ke terms mein).
  2. X̄, Ȳ formula mein daalo.
  3. Parameter (x, y ya t) ko eliminate karo → X̄, Ȳ ke beech relation = evolute.

Properties

  • Curve ka normal evolute ka tangent hota hai.
  • Do points ke radii of curvature ka difference = evolute ke corresponding arc ki length.
  • Ek curve ka evolute unique hai, par involutes infinite hote hain (string unwinding — gear teeth profile involute hota hai).
Solved Example Parabola y² = 4ax ka evolute.
x = at², y = 2at ⇒ y1 = 1/t, y2 = −1/(2at³), 1+y1² = (t²+1)/t².
X̄ = at² + 2a(t²+1) = 3at² + 2a,   Ȳ = 2at − 2at(t²+1) = −2at³.
(X̄−2a)³ = 27a³t⁶, Ȳ² = 4a²t⁶ ⇒ 27aY² = 4(X−2a)³ (semi-cubical parabola).
Yaad Rakho Ellipse x²/a²+y²/b²=1 ka evolute: (ax)2/3 + (by)2/3 = (a²−b²)2/3. Astroid x2/3+y2/3=a2/3 ka evolute: (x+y)2/3+(x−y)2/3 = 2a2/3.

UNIT II Calculus — Mean Value Theorems, Expansions, Limits, Extrema

1. Rolle's Theorem

Statement Agar f(x) (i) continuous hai [a,b] par, (ii) differentiable hai (a,b) mein, aur (iii) f(a) = f(b), to kam se kam ek c ∈ (a,b) exist karega jahan f'(c) = 0.

Geometrical meaning: curve par kam se kam ek point aisa hai jahan tangent x-axis ke parallel hai.

Example f(x) = x² − 4x + 3 on [1,3]. Polynomial ⇒ continuous & differentiable. f(1) = 0 = f(3). f'(c) = 2c − 4 = 0 ⇒ c = 2 ∈ (1,3). Verified.
Fail case f(x)=|x| on [−1,1]: f(−1)=f(1) par x=0 par differentiable nahi ⇒ Rolle's apply nahi hota.

2. Mean Value Theorems

(a) Lagrange's Mean Value Theorem (LMVT)

Agar f continuous [a,b] par aur differentiable (a,b) mein, to ∃ c ∈ (a,b):

LMVTf'(c) = f(b) − f(a)b − a    ya    f(a+h) = f(a) + h f'(a+θh), 0<θ<1

Meaning: chord AB ke parallel kam se kam ek tangent hai. Rolle's = LMVT ka special case (f(a)=f(b)).

Example f(x) = x³ on [0,2]: f'(c) = 3c² = (8−0)/(2−0) = 4 ⇒ c = 2/√3 ≈ 1.155 ∈ (0,2). Verified.

(b) Cauchy's Mean Value Theorem

f, g dono continuous [a,b] par, differentiable (a,b) mein, aur g'(x) ≠ 0, to ∃ c ∈ (a,b):

CMVTf(b) − f(a)g(b) − g(a) = f'(c)g'(c)
Example f = eˣ, g = e−x on [a,b]. LHS = (eb−ea)/(e−b−e−a) = −ea+b. RHS = ec/(−e−c) = −e2c. ⇒ c = (a+b)/2 (A.M. of a, b). g(x)=x lene par CMVT → LMVT ban jata hai.

5. Maxima and Minima

(a) One variable

  1. f'(x) = 0 solve karo → stationary points.
  2. f''(x) < 0 ⇒ maximum; f''(x) > 0 ⇒ minimum.
  3. f'' = 0 ho to higher derivative: pehla non-zero derivative even order ka ho to extremum (negative → max), odd ho to neither (point of inflexion).
Example f = x³ − 6x² + 9x + 1. f' = 3(x−1)(x−3) = 0 ⇒ x = 1, 3. f'' = 6x − 12.
x=1: f''=−6 < 0 ⇒ max, f(1) = 5.
x=3: f''=6 > 0 ⇒ min, f(3) = 1.

(b) Two variables f(x,y)

  1. fx = 0, fy = 0 solve → stationary points.
  2. r = fxx, s = fxy, t = fyy nikalo.
ConditionResult
rt − s² > 0, r < 0Maximum
rt − s² > 0, r > 0Minimum
rt − s² < 0Saddle point (no extremum)
rt − s² = 0Doubtful — further study
Example f = x³ + y³ − 3axy (a > 0). fx = 3x² − 3ay = 0, fy = 3y² − 3ax = 0 ⇒ points (0,0), (a,a). r = 6x, s = −3a, t = 6y.
(a,a): rt − s² = 36a² − 9a² = 27a² > 0, r = 6a > 0 ⇒ minimum, fmin = −a³.   (0,0): rt − s² = −9a² < 0 ⇒ saddle point.
Lagrange's multipliers Constraint φ(x,y,z)=0 ke saath f extremise karna ho: F = f + λφ banao, Fx=Fy=Fz=0 aur φ=0 solve karo. (Jaise: x+y+z = a fixed ho to xyz max at x=y=z=a/3.)

UNIT III Sequences, Series and Fourier Series

1. Convergence of Sequence

Definition Sequence {an} convergent hai agar limn→∞ an = l (finite, unique). Limit ±∞ ho to divergent; alag-alag values ke beech jhoole to oscillatory.

• {1/n} → 0 : convergent

• {(1+1/n)ⁿ} → e : convergent

• {n²} → ∞ : divergent

• {(−1)ⁿ} : oscillates finitely

• Monotonic + bounded ⇒ convergent

• Convergent ⇒ bounded (converse false)

2. Convergence of Series and Tests

Series Σun ke partial sum Sn = u1+…+un. Agar lim Sn finite ⇒ series convergent.

Necessary condition Σun convergent ⇒ lim un = 0. Converse false: Σ1/n mein un→0 par series diverge karti hai. Isliye lim un ≠ 0 ⇒ seedha divergent.
Geometric Σ rⁿ: convergent if |r| < 1 (sum a/(1−r)); divergent if r ≥ 1; oscillatory if r ≤ −1.
p-series Σ 1/nᵖ: convergent if p > 1, divergent if p ≤ 1. (Comparison ke liye sabse useful.)

3. Power Series and Taylor's Series

Power series: Σ anxⁿ = a0 + a1x + a2x² + … . Ye |x| < R ke liye (absolutely) convergent, |x| > R ke liye divergent; x = ±R par alag se check karo.

Radius of convergenceR = limn→∞ |an / an+1|    ya    1/R = lim |an|1/n
Example Σ xⁿ/n: an/an+1 = (n+1)/n → 1 ⇒ R = 1. x = 1: Σ1/n divergent. x = −1: Σ(−1)ⁿ/n convergent (Leibnitz). ⇒ Interval of convergence [−1, 1).

Taylor's series: agar f ke sabhi derivatives exist karein aur remainder Rn → 0, to f(x) = Σn=0∞ f(n)(a)(x−a)ⁿ/n! (a = 0 par Maclaurin's series). Ye ek power series hai in (x−a). Example: eˣ ki series sab x ke liye converge karti hai (R = ∞); log(1+x) ki R = 1.

4. Fourier Series

Periodic function ko sine aur cosine terms ke infinite sum mein likhna. Dirichlet conditions: f periodic, single-valued, finite; finite number of discontinuities aur maxima/minima ek period mein. Discontinuity par series = [f(x⁻)+f(x⁺)]/2.

Interval (−π, π) or (0, 2π)f(x) = a0/2 + Σn=1∞(an cos nx + bn sin nx) a0 = (1/π)∫f(x)dx,   an = (1/π)∫f(x)cos nx dx,   bn = (1/π)∫f(x)sin nx dx (integration over one period of length 2π). Interval (−l, l) ho to nx → nπx/l aur 1/π → 1/l.
Even / Odd in (−π,π) f even ⇒ bn = 0 (sirf cosine). f odd ⇒ a0 = an = 0 (sirf sine).
Useful: sin nπ = 0, cos nπ = (−1)ⁿ.
Example f(x) = x in (−π,π) (odd): bn = (2/π)∫0πx sin nx dx = 2(−1)n+1/n
⇒ x = 2(sin x − sin2x/2 + sin3x/3 − …)

Half Range Sine and Cosine Series

Jab f(x) sirf (0, π) [ya (0, l)] mein diya ho, to use odd extension karke sine series ya even extension karke cosine series mein expand karte hain.

Parseval's Theorem

Parseval's identity (−π, π) par: (1/π)∫−ππ [f(x)]² dx = a0²/2 + Σ(an² + bn²)
Half range (0, l): sine series ⇒ (2/l)∫0l f² dx = Σ bn² ;   cosine series ⇒ (2/l)∫0l f² dx = a0²/2 + Σ an².
Example x = 2Σ(−1)n+1 sin nx/n in (−π,π), bn² = 4/n². LHS = (1/π)∫−ππx²dx = (1/π)(2π³/3) = 2π²/3. ⇒ 2π²/3 = 4Σ1/n² ⇒ Σ 1/n² = π²/6.

UNIT IV Vector Spaces

1. Vector Space

Definition Non-empty set V, field F (R ya C) ke upar vector space hai agar do operations — vector addition (u+v) aur scalar multiplication (αu) — define hon aur ye axioms satisfy karein (∀ u,v,w ∈ V, α,β ∈ F):

A1. Closure: u + v ∈ V

A2. Commutative: u + v = v + u

A3. Associative: (u+v)+w = u+(v+w)

A4. Zero vector 0: u + 0 = u

A5. Inverse −u: u + (−u) = 0

M1. Closure: αu ∈ V

M2. α(u+v) = αu + αv

M3. (α+β)u = αu + βu

M4. (αβ)u = α(βu)

M5. 1·u = u

Examples: Rⁿ (n-tuples), Pn (degree ≤ n polynomials), Mm×n (all m×n matrices), C[a,b] (continuous functions). Non-example: set of polynomials of exactly degree 2 (sum ka degree gir sakta hai → closure fail).

2. Vector Sub Space

Definition V ka non-empty subset W subspace hai agar W khud usi addition & scalar multiplication ke saath vector space ho.
One-step test W subspace ⇔ αu + βv ∈ W for all u, v ∈ W, α, β ∈ F. (Shortcut: 0 ∈ W hona hi chahiye — agar nahi to subspace nahi.)
Yes W = {(x, y, 0)} ⊂ R³ (xy-plane): α(x1,y1,0)+β(x2,y2,0) = (…, …, 0) ∈ W ✓.
W = {(x,y,z): x+y+z = 0} bhi subspace hai.
No W = {(x, y): x + y = 1}: (0,0) ∉ W ⇒ subspace nahi.
W = {(x,y): x ≥ 0}: (−1)(1,0) ∉ W ⇒ nahi.

Facts: do subspaces ka intersection hamesha subspace; union generally nahi (sirf jab ek dusre ke andar ho). {0} aur V khud trivial subspaces hain.

3. Linear Combination of Vectors

v = α1v1 + α2v2 + … + αnvn (αi scalars) ko v1,…,vn ka linear combination kehte hain. Saare possible linear combinations ka set = span L(S), jo hamesha ek subspace hota hai.

Example (3, 5) ko (1,1) aur (1,2) ke LC mein likho: a(1,1)+b(1,2) = (3,5) ⇒ a + b = 3, a + 2b = 5 ⇒ b = 2, a = 1. ∴ (3,5) = 1·(1,1) + 2·(1,2). (Equations inconsistent hon to LC possible nahi.)

4. Linearly Dependent and Linearly Independent Vectors

Definition α1v1 + … + αnvn = 0 ka sirf trivial solution (sab αi = 0) ho ⇒ Linearly Independent (LI). Koi non-zero αi se bhi zero ban jaye ⇒ Linearly Dependent (LD) (yaani koi vector baaki ka LC hai).
Example (LD) (1,2,3), (2,3,4), (3,4,5):
det = 1(15−16) − 2(10−12) + 3(8−9) = −1+4−3 = 0 ⇒ LD. Relation: v1 + v3 = 2v2.
Example (LI) (1,0,0), (1,1,0), (1,1,1): det of matrix = 1 ≠ 0 ⇒ LI.
Yaad Rakho (i) n vectors Rⁿ mein: det ≠ 0 ⇒ LI, det = 0 ⇒ LD. Generally: rank of matrix of vectors = number of vectors ⇒ LI. (ii) Zero vector wala set hamesha LD. (iii) Do vectors LD ⇔ ek dusre ka scalar multiple. (iv) Rⁿ mein n se zyada vectors hamesha LD.

6. Linear Transformations

Definition T : U → V linear transformation hai agar (i) T(u + v) = T(u) + T(v), (ii) T(αu) = αT(u). Combined: T(αu + βv) = αT(u) + βT(v).

• T(0) = 0 hamesha (check karne ka shortcut).

• Kernel (null space): ker T = {u : T(u) = 0}, dim = nullity.

• Range: R(T) = {T(u)}, dim = rank.

• Har LT T: Rⁿ → Rᵐ ko m×n matrix A se likh sakte hain: T(X) = AX.

Rank-Nullity Theoremrank(T) + nullity(T) = dim U
Example 1 T(x,y) = (x+y, x−y): T(αu+βv) = αT(u)+βT(v) check ⇒ linear.
T(x,y) = (x+1, y): T(0,0) = (1,0) ≠ 0 ⇒ not linear.
Example 2 T(x,y,z) = (x+y, y+z). ker: x+y=0, y+z=0 ⇒ (x,y,z) = k(1,−1,1) ⇒ nullity = 1. Range = R² ⇒ rank = 2. Check: 2 + 1 = 3 = dim R³ ✓.

UNIT V Matrices

1. Rank of a Matrix

Definition Matrix A ka rank ρ(A) = r agar kam se kam ek r-order minor non-zero ho aur (r+1)-order ke saare minors zero hon. Rank elementary transformations se change nahi hota.

Elementary transformations: (i) Ri ↔ Rj (ii) Ri → kRi, k ≠ 0 (iii) Ri → Ri + kRj (same for columns).

Echelon form: har non-zero row ka pehla non-zero element pichhli row se right mein; zero rows neeche. Rank = number of non-zero rows.

Normal form: [Ir 0; 0 0] — yahan r = rank. PAQ = N form bhi isi se aata hai.

Example A = [1 2 3; 2 4 6; 1 1 1].
R2→R2−2R1, R3→R3−R1: [1 2 3; 0 0 0; 0 −1 −2].
R2↔R3: [1 2 3; 0 −1 −2; 0 0 0] ⇒ ρ(A) = 2.

2. Solution of Simultaneous Linear Equations by Elementary Transformation

System AX = B ke liye augmented matrix [A | B] banao, sirf row transformations se echelon (Gauss elimination) form mein lao, phir back-substitution karo. (Gauss-Jordan mein [A|B] → [I|X] tak le jaate hain.)

Example x+y+z = 6, x+2y+3z = 14, x+4y+7z = 30.
[1 1 1 | 6; 1 2 3 | 14; 1 4 7 | 30] → R2−R1, R3−R1 → [1 1 1 | 6; 0 1 2 | 8; 0 3 6 | 24] → R3−3R2 → [1 1 1 | 6; 0 1 2 | 8; 0 0 0 | 0].
ρ(A) = ρ(A|B) = 2 < 3 ⇒ infinite solutions. z = k ⇒ y = 8 − 2k, x = 6 − y − z = k − 2. Solution: (k−2, 8−2k, k).

Exam favourite x+y+z = 6, x+2y+3z = 10, x+2y+λz = μ. Reduce: [1 1 1|6; 0 1 2|4; 0 0 λ−3|μ−10].

4. Eigen Values and Eigen Vectors

Definition Square matrix A ke liye agar non-zero vector X aur scalar λ aise hon ki AX = λX, to λ = eigen value (characteristic root) aur X = eigen vector. Eigen values characteristic equation |A − λI| = 0 se milte hain; har λ ke liye (A − λI)X = 0 solve karke X.
3×3 shortcutλ³ − (trace A) λ² + (sum of principal minors of order 2) λ − |A| = 0 2×2 ke liye: λ² − (trace)λ + |A| = 0.
Example 2×2 A = [2 1; 1 2]: λ² − 4λ + 3 = 0 ⇒ λ = 1, 3.
λ = 3: [−1 1; 1 −1]X = 0 ⇒ x = y ⇒ X = (1, 1)ᵀ.
λ = 1: [1 1; 1 1]X = 0 ⇒ x = −y ⇒ X = (1, −1)ᵀ.
Example 3×3 A = [1 1 3; 1 5 1; 3 1 1]: trace = 7, minors sum = 4 − 8 + 4 = 0, |A| = −36.
λ³ − 7λ² + 36 = 0 ⇒ λ = −2, 3, 6.
Eigen vectors: (−1,0,1), (1,−1,1), (1,2,1).

Properties of eigen values

1. Sum of eigen values = trace (sum of diagonal)

2. Product of eigen values = |A|

3. Triangular/diagonal matrix: eigen values = diagonal elements

4. A aur Aᵀ ke eigen values same

5. A−1 ke eigen values 1/λ; Ak ke λk; kA ke kλ

6. Real symmetric matrix ke eigen values real; eigen vectors orthogonal

7. Koi eigen value 0 ⇔ |A| = 0 (singular)

8. Distinct eigen values ke eigen vectors LI

5. Cayley-Hamilton Theorem and Inverse

Statement Har square matrix apni characteristic equation ko satisfy karti hai. Agar |A − λI| = λⁿ + c1λn−1 + … + cn = 0, to An + c1An−1 + … + cnI = 0.
Inverse Dono side A−1 se multiply (cn = ±|A| ≠ 0):A−1 = −(1/cn) [An−1 + c1An−2 + … + cn−1I] Applications: A−1 nikalna, higher powers (A³, A⁴ …) ko lower powers mein likhna.
Example 2×2 A = [1 2; 3 4]: λ² − 5λ − 2 = 0 ⇒ A² − 5A − 2I = 0 ⇒ A−1 = (A − 5I)/2 = ½[−4 2; 3 −1] = [−2 1; 3/2 −1/2].
Example 3×3 A = [2 −1 1; −1 2 −1; 1 −1 2]. trace = 6, principal minors = 3+3+3 = 9, |A| = 4.
Char. eq.: λ³ − 6λ² + 9λ − 4 = 0 ⇒ (C-H) A³ − 6A² + 9A − 4I = 0 ⇒ A−1 = (A² − 6A + 9I)/4.
A² = [6 −5 5; −5 6 −5; 5 −5 6] ⇒ A² − 6A + 9I = [3 1 −1; 1 3 1; −1 1 3] ⇒ A−1 = ¼[3 1 −1; 1 3 1; −1 1 3].
Verify: A·A−1 ki row1·col1 = (6 − 1 − 1)/4 = 1 ✓. C-H verify karne ke liye pehle A², A³ nikalkar equation mein daal kar zero matrix dikhao.
Yaad Rakho Signs: 3×3 mein λ³ − Sλ² + Pλ − |A| (S = trace, P = minors ka sum). C-H se A−1 mein last constant (|A|) se divide hota hai — |A| = 0 ho to inverse exist nahi karta.
